Starter Code Analysis

- Console-based Library Management System that allows users to manage
- books, library users, and borrow or return books.
- Blazor Application will replicate the following functions:

1. Book Management: Displays a list of available books, including their ID, title, author, and ISBN. Implements CRUD functions to books and read and save information using Books.csv
2. User Management: Display a list of library users, inclduing their ID, name, and email. Also implements CRUD functions for users and reads and saves information uisng Users.csv.
3. Borrowing Books: Allows users to select and borrow books from the library.
4. Returning Books: Allows user to view their borrowed books and return them.


- The interface will replace the console menues and text prompts with Blazor web pages.
- Display book and user information in tables
- Provide navigation between book management, user management, borrowing, and returning pages.
